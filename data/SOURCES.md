# Sources

Everything in `data/` either came from a public BC government source listed here, was computed by code from those sources, came out of the agent run, or was written by hand and is labelled as such. Nothing is mock data. All retrievals were on 2026-10-15, one request at a time with a pause between them.

## Collected

| Source | URL | Retrieved | Used for |
|---|---|---|---|
| ARIS index (BC Geographic Warehouse WFS, layer `WHSE_MINERAL_TENURE.ARIS_MINERAL_REPORTS`) | `https://openmaps.gov.bc.ca/geo/pub/wfs?service=WFS&version=2.0.0&request=GetFeature&typeName=pub:WHSE_MINERAL_TENURE.ARIS_MINERAL_REPORTS&outputFormat=application/json&CQL_FILTER=PROPERTY_NAME%20ILIKE%20%27%25IRON%20LAKE%25%27` | 2026-10-15 (server timestamp 18:06:39 UTC) | `index.json`: the 22 Iron Lake records, only the fields the site uses (year, operator, title, author, work types, reported spend, coordinates, map sheets). The raw dump stays in `private/`. |
| ARIS detail pages, one per record | `https://apps.nrs.gov.bc.ca/pub/aris/detail/<number>` for 26534, 26937, 27220, 27546, 28230, 29078, 29930, 30800, 31432, 32234, 32717, 33704, 34595, 35827, 36430, 36807, 38640, 39870, 40980, 41327, 41800, 43017 | 2026-10-15 | Page counts, file names and off-confidential dates in `index.json` and `corpus.json`. 43017 (2025 geochronology and green rock study) is listed with no file and "Pending review". |
| ARIS report PDFs, the seven corpus reports | `https://apps.nrs.gov.bc.ca/pub/aris/Report/<number>.pdf/` for 34595, 36430, 36807, 38640, 40980, 41327, 41800 | 2026-10-15 | Page text for the agent and the checker. | BC Data Catalogue, ARIS dataset | `https://catalogue.data.gov.bc.ca/api/3/action/package_show?id=af68d1d1-b85e-4ea9-b5f3-e09fc83f3f4f` | 2026-10-15 | Licence check: "Access Only". |
| BC government copyright page (linked from ARIS) | `http://gov.bc.ca/copyright` (redirects to `https://www2.gov.bc.ca/gov/content/home/copyright`) | 2026-10-15 | "It may not be reproduced or redistributed without the prior written permission of the Province of British Columbia." |

Because of the last two rows, the site ships no page images and no copies of the PDFs. It ships short quotes with attribution and deep links to each page on ARIS (`<pdf url>#page=N`). Each claim ships at most 400 characters of its page, counting the quote as written: the quote, then a little context if there is room; a longer quote is cut to the part around its value. If a page's claims together would ship more than half of its text, context goes first, then long text quotes shrink to their value. `excerpts.json` lists the pages still over half and the share of each report shipped.

PDF page numbers are the page in the PDF file, not the number printed on the page. The agent reads 41327 and 41800 from PDF page 5 to the end of the report body (49 and 45). Their appendices hold the drill logs and lab certificates; code reads the collar tables (41327 p30 and p51, 41800 p33 and p162) and the lab assay tables (41327 p387 to p564, 41800 p411 to p436) there, to settle disagreements and check the agent's intervals. The agent never reads those pages.

## Computed by code from the collected sources

| File | What | Script |
|---|---|---|
| `corpus.json` | The seven reports, page ranges used, sizes, links, scanned pages | `agent/build_data.py` |
| `normalization.json` | Every non-ASCII character in the corpus text and what the checker's normalization does with it | `agent/scan_chars.py` |
| `excerpts.json` | For each claim, its quote inside a short excerpt of its page, with the highlight span | `agent/build_data.py` |
| `shipped.json` | The share of each report's text the site ships, counted over every file the site imports, and the pages still over half | `agent/shipped.py`, `agent/build_data.py` |
| `fields.json` (settled_by, lab, lab_summary, code_pages) | What the reports' drill tables settle, the rows code read, the lab check of every claimed interval, and map sheet labels read from every page | `agent/extract_tables.py`, `agent/rules.py` |
| `summary.json` | The summary's kept sentences and their citations, every sentence code threw out and why, the session's calls, and the points it made | `agent/build_data.py`, `agent/card.py` |
| `scanned_pages.json` | Pages that are scans (one image over at least 85% of the page, with a text layer), and the image check of each cited one | `agent/extract_pages.py`, `agent/build_data.py` |
| `fields.json` | Field states, groups and code lines from the disagreement rules | `agent/rules.py` |
| `eval/scores.json`, `eval/answers.json` | Verdicts and scores from the gold answers | `agent/score.py` |
| `eval/search_log.json` | Full-text searches behind each unanswerable question | `agent/check_gold.py` |

## Generated by the agent run

| File | What |
|---|---|
| `claims.json` | Every claim the agent proposed that the checker accepted, with its check result |
| `rejected.json` | Every claim the checker threw out, the reason, and whether a retry fixed it |
| `traces.json` | Each session's tool calls, summarized (never full page text) |
| `run.json` | Model, CLI version, date, prompt and tool hashes, tool list, sessions, number of full runs and why |
| `eval/answers.json` | The agent's answer line and claims for each eval question |

Model: Claude (`claude-opus-5-5`) through the `claude` CLI 2.1.299, effort high, with only the four corpus tools, run on 2026-10-15. Two full runs; the site uses run 2 (`2026-10-15-r2`: 12 field sessions and 15 eval sessions, 528 claims accepted and 22 thrown out). Why there were two is in `eval/changes.json`, and run details are in `run.json`.
